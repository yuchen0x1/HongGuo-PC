# 红果短剧 6.4

状态：发行候选（内部版本 `6.4.0`，标签 `v6.4`）。自 6.2 起项目仅发布和维护 Windows x64，macOS 不属于发行范围。Windows EXE 未配置代码签名。

## 主要变化

### 播放交互升级

- 双击视频画面或播放区空白处进入／退出全屏，保持当前播放或暂停状态；控制栏、输入框、按钮与对话框内的双击不触发。
- 空格短按仍为播放／暂停；长按 300ms 进入临时 2 倍速，松开按键或窗口失焦立即恢复原倍速，临时倍速不覆盖用户偏好。
- 快捷键新增「长按临时 2 倍速」独立绑定项（默认空格，与播放／暂停同键兼容），旧版本保存的快捷键配置自动继承播放键，无需重新设置。
- 音量、静音状态与常用倍速跨剧集、跨页面并跨重启记忆；临时 2 倍速不会写入偏好。

### 切集无黑屏

- 切集、自动连播与兼容转码切换时保留上一集的最后一帧，直到新片源首帧真正提交上屏后才切换，消除此前的黑屏／白屏闪烁。
- 保留帧仅存在于播放器舞台内部，不写入下载目录，也不影响弹幕与画质增强图层。

### 系统播放器打开

- 已完整下载的本集可在播放器顶部直接用「系统播放器」按钮打开，调用系统为 MP4 关联的默认程序（VLC、PotPlayer 等）。
- 主进程仅允许打开本剧已登记、状态为完成且后缀为 `.mp4` 的文件，并再次校验媒体归属，拒绝任意路径打开。

### 取源修复与安全加固

- 修复部分明确未加密片源被误判为缺少解密信息导致的取源失败；同时兼容 `encrypt_info` 与 `encrypt` 两种加密标记位置。
- 仅提供 ByteVC2 编码的剧集给出明确提示，不再笼统报为网络或解析失败。
- 依赖安全更新：`joi` 覆盖提升至 17.13.9（消除多次邮箱分割正则的二次复杂度 DoS 公告），`follow-redirects` 升至 1.16.2，`fast-uri` 升至 3.1.9，`undici` 传递依赖同步至安全版本。
- 构建期工具链同步升级以消除已知公告：Vite 升至 6.4.5（修复优化依赖 `.map` 路径穿越），esbuild 升至 0.25.12（修复开发服务器跨站读取），并对 electron-builder 内部的 `minimatch` 做定向覆盖至 11.0.5（`glob@7` 与 `filelist` 保留其兼容版本，避免打包阶段回归）。
- 本地媒体协议继续使用进程内随机不可猜地址、仅允许视频后缀、CORS 来源与发起方双重校验；外部链接打开继续限定 http/https 且拒绝含凭据地址。
- 修复 Windows 平台软链接用例因 `EPERM`（无管理员／开发者模式权限）导致的整轮测试失败：本机 `npm test` 现在可完整通过。

### Cyber HUD 界面升级

- 视窗顶部新增深空光谱能量线；侧边栏与顶栏改为分层玻璃拟态，激活项使用霓虹能量条与外发光。
- 主操作按钮加入对角扫描流光与悬停外发光；输入框聚焦切换为主题色光晕；命令面板改为高深度全息玻璃。
- 发现页海报悬停上浮并浮出蓝红双色全息描边与光轨；播放按钮为霓虹光晕胶囊；集数与来源角标升级为玻璃徽标。
- 播放器舞台增加青色轮廓光，控制条与分集弹层使用深色玻璃渐变；当前集分集芯片为红晕全息态。
- 搜索与下载页卡片、分集选择格、下载进度条升级为霓虹能量槽与青色队列脉冲灯。
- 所有动效仅使用 `transform` / `opacity` 合成器属性，并在 `prefers-reduced-motion` 下自动停止。
