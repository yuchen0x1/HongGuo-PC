# 红果短剧 6.39 发行（修复安装包截断）

6.39（内部 `6.39.0`）在 2026-11-26 两次上传：第一次的安装包把主程序截断写入，安装后无法启动，该包已撤回删除；重新构建的 6.39 已通过安装载荷校验与安装后播放实测，正式发布。功能与 6.38 相同。

## 缺陷与根因

- 现象：安装第一版 6.39 后启动报"此应用无法在你的电脑上运行"。
- 证据：把该安装包装进独立临时目录，落地的 `红果短剧.exe` 为 103,537,547 字节，是构建产物 `dist/win-unpacked/红果短剧.exe`（250,521,088 字节）的前半截；`app.asar`（`7565aed2…`）与 FFmpeg/FFprobe 资源完整；安装器退出码 0、无报错。
- 对照：同一台机器安装 6.37、6.38 的安装包，主程序均为完整的 250,521,088 字节。
- 结论：缺陷在那一版 NSIS 打包过程，把主程序以截断状态写入安装包；构建日志无警告，磁盘余量充足。项目位于云同步目录，同步/占用在打包读取时可能造成静默截断，但未取得直接证据，不作定论。
- 影响：该包的全新安装与自动更新安装都会得到无法启动的应用；6.38 及更早版本不受影响。

## 修复

- 重新构建安装包：先把 `dist/win-unpacked` 复制到 **不参与云同步的临时目录**并逐文件校验摘要，再用 `electron-builder --prepackaged` 从该副本打包，避免打包时读到同步盘上被占用/半截的文件。第一次原地重建仍然生成了"只释放卸载器、没有主程序"的空包，改用暂存副本后通过校验。
- 新增 `scripts/check-installer-payload.cjs`：把安装包装进独立临时目录，逐字节比对 `红果短剧.exe`、`resources/app.asar`、`resources/bin/ffmpeg.exe`、`resources/bin/ffprobe.exe` 与构建产物，并校验主程序为 x64 PE 镜像；不一致即失败，没有本地构建产物时跳过（CI 不构包）。
- 发布门禁：安装包通过载荷校验，并用**安装出的程序**完成逐集播放实测后才允许发布。
- 许可与开源：完整源码在公开仓库；`NOTICE` 与 `README` 恢复为"完整源码见本仓库"。"源码不进仓库"的临时做法作废，v6.38/v6.39 的取源修复现已在公开 `main` 上。

## 覆盖与限制

- 只逐集验证目标剧第 6、22、34、68、88 集；其他剧集仍按线路逐集判断。

- 第一版 6.39 的用户无法通过应用内更新自救（应用无法启动），需要手动安装本版。
