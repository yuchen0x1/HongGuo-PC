## 📢 版本概述

本次修复安装包问题：此前上传的 6.39 安装包把主程序截断写入，安装后应用无法打开，该包已撤回删除。重新构建的 6.39 已逐项核对安装结果，安装后正常启动与播放。功能与 6.38 相同；完整源码继续在公开仓库维护。

## 🔧 改进与优化

- **发布前安装校验**：新增校验脚本，把待发布的安装包装进独立临时目录，逐字节比对安装出的主程序、`app.asar`、`ffmpeg.exe`、`ffprobe.exe` 与构建产物，并校验主程序为 x64 可执行文件；任何不一致都阻止发布。
- **源码维护**：完整源码继续在公开仓库维护，安装包内 NOTICE 与 README 的源码说明同步保持一致。

## 🐛 问题修复

- **安装后无法启动**：撤回的 6.39 安装包内含的主程序被截断为 103,537,547 字节（完整为 250,521,088 字节），Windows 提示"此应用无法在你的电脑上运行"。本版重新打包，安装结果与构建产物逐字节一致。
- **旧包对照**：6.37、6.38 的安装包在独立目录安装后主程序均完整，该缺陷只出现在撤回的那个 6.39 安装包。

## 🔒 安全与兼容性

- **许可不变**：仍整体以 GPL-3.0 授权，完整源码在公开仓库，派生关系与上游致谢保持原样。
- **兼容性**：设置、剧库、观看记录与下载记录格式与 6.38 一致，可直接覆盖升级。
- **平台范围**：仅 Windows x64。
