## 📢 版本概述

本次更新修复 Windows 播放链路中的线路判断、旧视频状态残留和故障诊断问题，保留现有界面、播放器、缓存后续、连播与兼容模式。播放源请求、响应解析、媒体加载和真实画面确认分别记录，不能再用进度数字或取得地址代表播放成功。

**第 22 集及中后段播放问题尚未取得真实修复证据。** 本轮主要检查目标剧第 6、22、34、68、88 集；本版改正已确认的客户端缺陷，公开第 1、2 集只作播放器基础对照，不将其可播表述为后续集或整部剧已恢复。

## ✨ 新增功能

- **逐次播放诊断**：每次播放生成独立诊断 ID，可展开请求、解析、地址检查、媒体加载、解码和首帧步骤，查看实际 HTTP 状态与各线路事件，并复制或导出脱敏报告。

## 🔧 改进与优化

- **播放确认**：当前视频会话取得真实呈现帧后才确认画面播放，切集后的旧事件不能给新集写入成功状态、进度或预取依据。
- **故障处理**：区分网络、超时、业务错误、数据解析、空片源、地址到期、清单/媒体请求、格式与解码问题；明确异常停止重复自动请求，临时故障继续有界恢复。
- **媒体格式**：根据地址及响应类型处理 MP4、现有 HLS 路径和未知格式；DASH 返回明确的不支持提示，不再按 MP4 处理。

## 🐛 问题修复

- **线路过早停止**：官网分集页面返回 404/410 时，保留独立 App 提供方的合法尝试；明确拒绝、限流、账号或内容保护条件仍停止，不扩大访问权限。
- **黑屏仍有旧时间**：取源失败时清理旧视频资源，当前媒体不可用时控制栏归零，避免前一集的时间和时长残留。
- **诊断信息丢失**：保留故障阶段、原始安全状态码与 HTTP 状态，官网缺集和 App 空响应分别展示，不再压成一句模糊提示。
- **公开媒体回退**：为可选时长参考请求设置独立期限，避免消耗后续合法公开片源的全部请求时间；继续严格核对本集身份和完整时长。
- **分集隔离**：加强 App 模型身份与完整性校验，当前集首帧前不推进历史或触发后续预取，失败与切集及时释放旧资源。
- **旧官网路径校验**：旧 HTML 直链同样核对本集公开许可、真实 MP4 字节和完整时长，不将预览或错误页面当作完整媒体。
- **共享媒体与同步目录**：单个读取取消不再连带终止其他读取的 HLS 准备；同步目录不支持硬链接时使用独占复制发布，继续防止覆盖已有文件。

## 🔒 安全与兼容性

- **诊断脱敏**：报告只保留允许的事件、状态与数值，不输出 Cookie、Token、设备唯一标识、签名或完整媒体地址。
- **授权范围**：不绕过登录、DRM、付费、证书校验或设备认证；Android APK 静态研究不代表取得额外播放授权。
- **平台范围**：仅维护 Windows x64，沿用现有 Chromium 原生视频与 FFmpeg 兼容路径。

- **主要中后段验收**：目标剧第 6、22、34、68、88 集最新精确官网页面均为 404，未取得合法完整媒体或首帧，实际播放未通过。另查当前真人剧分类 24 条目录，均声明公开范围 3 集，未发现符合所定条件的中后段公开候选；这是有界样本，不能推定全平台或账号权限。
- **播放器基础对照**：新 6.38 打包程序使用随机官方完整第 1、2 集，实际首帧、持续画面、拖动、倍速、全屏、画中画、暂停与重启恢复、损坏恢复后手动重试和真实 ended 连播通过；素材本身完整下载、摘要及整集静音解码另行通过。首包曾拖动失败，修复后重新构建并重测通过，失败历史保留。
- **公开在线基础对照**：新包从独立空下载库完成真实搜索、71 集详情、公开第 1 集首帧与持续 10 秒、拖动、真实 ended 1→2 及新进程重启后重新取源。使用既有 H.264 / 官网优先选项，App 各请求路线尝试为 0，不代表 App 服务或账号授权恢复。
- **HLS 专项**：30 项错误、4 项空间保护及使用真实素材的本地 HLS 转封装/ffprobe 回归通过；这不代表官方真实 HLS 或受保护媒体通过。
- **本地自动化与构建**：最终完整重跑主单元 765/765、失败 0、跳过 0，另有 117 项平台检查全部通过；依赖审计已知漏洞 0，React 和 Windows x64 NSIS 构建通过。平台内部重复测试不叠加计数，构建成功不代表安装或正式更新验收。
