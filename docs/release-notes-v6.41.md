## 📢 版本概述

本次更新修复官网分集目录改版后打开剧集失败的问题：当官网只返回 `v1_` 不透明分集标识时，应用会使用带 V5 签名的 App 目录请求恢复完整分集列表。既有播放线路、分集身份校验和下载流程保持不变。

## 🔧 改进与优化

- **分集目录恢复**：备用目录请求接入已有 V5 签名器，继续保留重试、空响应诊断和 19 位剧号精度。
- **真实素材检查**：质量集成夹具兼容官网当前的 `v1_` 标识和历史数字标识，避免页面格式变化造成误报。

## 🐛 问题修复

- **点击剧集后提示获取分集失败**：修复官网分集页改版与未签名备用接口同时变化导致的目录读取失败。

## 🔒 安全与兼容性

- **请求身份**：目录读取使用进程内匿名身份生成签名，不保存或上传账号 Cookie、Token、设备标识或签名地址。
- **许可与平台**：继续使用 GPL-3.0，正式发行范围为 Windows x64 NSIS 安装版。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `hongguo-downloader-6.41-win-x64-setup.exe` | Windows x64 | 向导式安装版 |
| `latest.yml` | Windows x64 | 应用内更新清单 |

- 首次安装：下载安装版并按向导完成安装。
- 已安装用户：Windows x64 安装版可通过应用内更新获取本版；`latest.yml` 会随 Release 保留。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级，不要求先卸载。
- **配置和数据**：保留现有设置、剧库、观看记录和下载任务。
- **回退方式**：回退前备份重要资料，再从历史 Release 手动安装旧版。
