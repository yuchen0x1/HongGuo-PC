# 红果短剧 6.27 发行说明

状态：源码发行目标 `6.27.0`，公开版本 `6.27`，标签 `v6.27`。上一正式版本为 6.26。仅支持 Windows x64。

## 本轮范围：下载队列健康快照（EV-005）

1. 下载管理的队列状态从“并发数 + 排队数”扩展为可解释快照：并发下载、等待队列、自动重试、需要人工处理、已完成分别统计。
2. 自动重试显示最近一次预计等待时间，并在存在无法自动恢复的任务时提示“磁盘、权限或来源问题不会自动重试”。
3. 状态条此前只在有活动下载时显示；现在只有自动重试或待人工处理任务时也显示，避免“程序看起来停了”的误判。
4. 排队数以任务 id 去重，`maxConcurrent` 与 `retryAt` 的非法值安全收敛，不产生负数或其他误导性时间。

## 兼容性

- `get-queue-status` 保留 `active`、`queued`、`maxConcurrent` 三个原有字段，新增字段只增不改。
- 不改变任务持久化格式、自动重试的触发条件与退避顺序、并发默认值、资料格式和安装升级方式。

## 回归

- `node --test src/native/download-queue-health.test.cjs`：2 项通过（重复队列项去重、非法/过期重试时间、并发边界）。
- `npm test`：单元测试与 111 项平台检查全部通过。
- `npm run build:react`：生产渲染构建通过。

## 验收边界与已知限制

- 本轮未做安装包级 GUI 验收：状态条在真实批量下载与长任务下的观感未真机确认。
- 未进行实时上游播放验收，也不宣称修复任何来源可用性问题。
- EV-004（下载前磁盘预检）、EV-006（来源错误分类）、EV-008（日志脱敏）仍待办，登记于 [自主待办](../AUTONOMOUS_TASKS.md)。
