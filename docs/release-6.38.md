# 红果短剧 6.38 发行与后续集播放验收

6.38（内部 `6.38.0`）已于 2026-11-26 正式发布，标签 `v6.38`，正式资产为 Windows x64 安装 EXE 与一一对应的 `latest.yml`。本轮修复「后续集取不到片源」，按用户要求以《嫌疑人的秘密2藏金生死线》第 22 集为主要验收，并分别验证第 6、34、68、88 集；第 1、2 集不再作为后续集可播的依据。

## 范围

- 取源线路：新增已实测可用的播放模型线路，并把线路顺序调整为「已验证线路在前」，避免上游来源的受保护模型把可用线路挡在后面；只有空响应才继续向下，业务拒绝、401/403/429 与 DRM 仍立即终止。
- 分集映射：备用分集列表要求集数有效、分集与集数都不重复，异常时明确报错，不再默认补成第 0 集。
- 搜索与详情：保留 19 位剧号的原始数字，避免超出安全整数范围后被四舍五入到另一部短剧。
- 播放确认与诊断：真实呈现帧才确认播放；区分线路、阶段、HTTP 状态与故障类型，报告脱敏。
- 界面、播放器、画中画、连播、下载与资料格式未改变。

## 源码政策

本版起播放取源的核心实现不随公开仓库发布。公开标签 `v6.38` 对应公开提交，其中不含本版的取源实现；正式安装包与更新清单照常发布。此前已公开的历史提交与文档保持原样，不回改。

- 仅验证目标剧的 5 个指定分集；其他剧集、其他集仍按线路逐集判断，不由此推广。

- 播放全程静音、音量 0；未做声音输出质量验收。
- 不绕过登录、DRM、付费、证书校验或设备认证；官网公开记录不等于账号或授权通过。
