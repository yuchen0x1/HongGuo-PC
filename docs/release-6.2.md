# 红果短剧 6.2

状态：源码发行目标，内部版本 `6.2.0`，公开标签拟为 `v6.2`。正式发布状态、冻结提交和资产回执将在完成各平台构建、校验与 Release 后补齐。Windows EXE 未配置代码签名；macOS arm64/x64 需在 Mac 构建机补齐，未验收前不标记为已发布。

## 主要变化

### 选集页同系列跨季切换

- 发现页与「搜索与下载」选集区可列出同来源、同剧名基组的各季，并一键切换；没有其他季时不显示入口。
- 与既有观看记录归组规则一致：同来源且季号基名完全相同；不自动合并模糊同名或跨来源剧集。
- 搜索结果检索各季时保留本机候选，联网失败不阻断已知季的切换；切换后重新加载当前季分集并默认选择可用集。

### 界面滚动打磨

- 隐藏全局与播放器内部滚动条，保留内容滚动操作。
- 更新播放器选集弹层滚动条样式。
