## 📢 版本概述

本次更新只调整许可与发行方式，应用功能与 6.38 相同：播放取源、播放器、下载、界面和资料格式均未改动。自本版起，每个发行版本的完整源码随 Release 附件一同提供，安装包内的 NOTICE 与 README 也同步说明源码获取方式。

## 🔧 改进与优化

- **对应源码随发行提供**：除安装包与更新清单外，每个版本新增 `hongguo-downloader-<版本>-source.tar.gz` 源码归档，与该版本安装包同页发布；许可仍为 GPL-3.0，不缩小任何既有权利。
- **6.38 源码补齐**：6.38 发行页已锁定不可追加附件，其对应源码归档 `hongguo-downloader-6.38-source.tar.gz` 与本次同页提供。
- **发行说明一致**：安装包内 NOTICE、README 与仓库说明统一描述源码获取位置，去掉旧版本遗留的过时描述。

## 🔒 安全与兼容性

- **许可不变**：继续整体以 GPL-3.0 授权，派生关系、上游致谢与第三方组件声明保持原样。
- **兼容性**：设置、剧库、观看记录与下载记录格式与 6.38 完全一致，可直接覆盖升级。
- **平台范围**：仅 Windows x64。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `hongguo-downloader-6.39-win-x64-setup.exe` | Windows x64 | 向导式安装版 |
| `latest.yml` | Windows x64 | 应用内更新清单，无需单独运行 |
| `hongguo-downloader-6.39-source.tar.gz` | 源码 | 本版本对应源码归档（GPL-3.0） |
