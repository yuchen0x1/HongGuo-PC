# 红果短剧 6.0

状态：6.0（内部 `6.0.0`）发布于二次开发仓库 [yuchen0x1/HongGuo-PC](https://github.com/yuchen0x1/HongGuo-PC)，标签 `v6.0`，公开版本名 `6.0`。Windows x64 安装包与便携 zip 已随 Release 发布；Mac arm64/x64 产物**未包含**（本轮构建机为 Windows，无法产出 Mac 包；`npm run build:mac` 脚本就绪，需在 Mac 上构建后补传）。Windows EXE 未签名（沿袭上游惯例）。应用内「检测更新」已切换到本仓库。

## 主要变化

### 界面

- Windows 改为无边框窗口 + 自定义标题栏：品牌区（新图标 + 红色光晕）、平滑拖动、双击最大化/还原、最小化/最大化/关闭按钮（悬停过渡、关闭红色警示、最大化和还原图标切换）。macOS 维持 `hiddenInset` 原生交通灯。实现要点与两条本机硬约束见 [titlebar-custom.md](titlebar-custom.md)。
- 新版应用图标全端接入：标题栏品牌区、侧栏 logo、窗口/任务栏、安装包（`build/icon.ico` 多尺寸）。
- 侧栏新增「更新日志」页：整合原设置页的公告通知（关闭普通/紧急公告、查看当前公告）与检测更新（自动检测开关、手动检查更新）；设置页对应两块移除。`Ctrl+K` 命令面板同步收录。
- 版本号初始化 `6.0.0`，侧栏底部显示 `v6.0`。

### 搜索与来源

- 跨来源同名去重合并：同一部短剧多平台收录时按归一化标题合并为一张卡片，显示「同剧 N 个来源」徽标并提示已合并条数；同名但集数差异过大视为翻拍不合并。
- 内置短剧资源站六源（苹果 CMS 协议）：金鹰/海盗/硕博默认开启，暴风/360/旺旺默认关闭，设置「内置来源」开关可控，配置固定防劫持。
- 自定义源播放页直链转换：无扩展名纯路径播放页自动推导同目录 `/index.m3u8` HLS 直链（三个站点实测）；解析页与 `.html` 页面维持拒收。
- 推荐短剧源模板已由内置来源取代（设置页自定义源区恢复原样）。

## 验证

- `npm test`：与本轮改动相关的全部单元与平台检查通过；3 项失败为 Windows 无符号链接权限的环境预置问题（nas-export/download-safety），与本轮改动无关。
- `node scripts/check-release-version.cjs`：PASS（1521 版本对，含 5.5 → 6.0 递进与命名回归）。
- 构建冒烟：`dist/win-unpacked/红果短剧.exe`（即便携包内容本体）实际启动，界面、自定义标题栏、新图标、侧栏「更新日志」、`v6.0` 版本号均正常。

## 限制

- Mac arm64/x64 的 App 与 DMG 本轮未构建、未签名公证、未上传；在 Mac 上执行 `npm run build:mac` 后补传到同一 Release。Mac 端应用内更新在此前不会命中本仓库附件。
- Windows 安装器未做安装/重装/升级资料保留回归（仅产物级启动冒烟）；EXE 未签名，首次运行可能有 SmartScreen 提示。
- 内置采集源为第三方公开接口，可用性随站点波动；播放页直链推导基于常见采集站模板，推导失败会在播放时明确报错。
- 本机为 Windows + 125% 缩放环境，标题栏在其它 DPI/多显示器组合未逐一验证；窗口边缘缩放待真机鼠标确认。
