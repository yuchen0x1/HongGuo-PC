# 红果短剧 6.39（已撤回，标签被 GitHub 保留）

**6.39 从未提供可用安装包，已撤回删除；请使用 [6.40](release-6.40.md)。**

## 经过

- 6.39 首次上传的安装包把主程序截断写入，安装后报"此应用无法在你的电脑上运行"，用户确认后删除发行。
- 修复版准备好后无法按原版本号重新发布：仓库启用"发行不可变"，GitHub 会永久保留已发布过的标签名，`git push` 与 API 创建 `v6.39` 均被拒（`tag_name was used by an immutable release`）。
- 因此修复版改用 6.40 发布；`v6.39` 在标签列表里不存在，也不会有可用资产。临时关闭不可变发行开关后标签仍不可复用，随后已恢复该保护。

## 缺陷记录（保留供排查）

- 现象：安装后启动报"此应用无法在你的电脑上运行"。
- 证据：把安装包装进独立临时目录，落地的 `红果短剧.exe` 为 103,537,547 字节，是构建产物（250,521,088 字节）的前半截；`app.asar`（`7565aed2…`）与 FFmpeg/FFprobe 资源完整；安装器退出码 0、无报错。
- 对照：同一台机器安装 6.37、6.38 的安装包，主程序均为完整的 250,521,088 字节。
- 原地重建也失败过一次：生成的安装包只释放卸载器、没有主程序。改用"暂存到非同步目录 → 校验 → 从副本打包"后通过。
- 结论：缺陷在 NSIS 打包阶段读到了被同步/占用而截断的输入，责任不在应用源码或用户环境；已由 `scripts/check-installer-payload.cjs` 门禁拦截。
