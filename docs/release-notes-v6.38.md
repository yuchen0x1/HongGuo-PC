## 📢 版本概述

本次更新修复了中后段分集一直取不到片源、无法播放的问题：第 22 集等后续集现在可以真正取到片源并连续播放，Windows 打包程序已逐集实测通过。分集映射和剧号精度同时加固，界面、播放器、画中画、连播与兼容模式保持不变。

## ✨ 新增功能

- **逐次播放诊断**：每次播放生成独立诊断 ID，可展开请求、解析、地址检查、媒体加载、解码和首帧步骤，查看实际 HTTP 状态与各线路事件，并复制或导出脱敏报告。

## 🔧 改进与优化

- **取源线路逐级尝试**：按已登记线路顺序尝试，只有空响应的线路才继续向下，明确拒绝（未登录、限流、内容保护）立即停止并如实报错，不再静默换路。
- **分集映射校验**：备用分集列表要求集数有效、分集与集数均不重复，异常时明确报错，不再默认补成第 0 集。
- **剧号精度**：搜索与详情保留 19 位剧号的原始数字，避免超大整数被四舍五入后进入另一部短剧。
- **播放确认**：当前视频会话取得真实呈现帧后才确认画面播放，切集后的旧事件不能给新集写入成功状态、进度或预取依据。

## 🐛 问题修复

- **中后段分集无法播放**：此前后续集的播放模型线路一直返回空正文，本版改走可用线路并调整线路顺序，第 6、22、34、68、88 集均实际取到片源并播放。
- **黑屏仍有旧时间**：取源失败时清理旧视频资源，当前媒体不可用时控制栏归零，避免前一集的时间和时长残留。
- **诊断信息丢失**：保留故障阶段、原始安全状态码与 HTTP 状态，不同线路的失败分别展示，不再压成一句模糊提示。
- **公开媒体回退**：为可选时长参考请求设置独立期限，避免消耗后续合法公开片源的全部请求时间；继续严格核对本集身份和完整时长。

## 🔒 安全与兼容性

- **诊断脱敏**：报告只保留允许的事件、状态与数值，不输出 Cookie、Token、设备唯一标识、签名或完整媒体地址。
- **授权范围**：不绕过登录、DRM、付费、证书校验或设备认证，不扩大内容授权范围。
- **平台范围**：仅维护 Windows x64，沿用现有 Chromium 原生视频与 FFmpeg 兼容路径。

## 🧪 验证结果

- **中后段分集播放**：`6.38.0` 打包程序在独立空资料目录下逐集实测，第 6、22、34、68、88 集均为 `playing`，实测时长 73.839 / 79.969 / 122.578 / 54.590 / 67.291 秒，每集连续播放 30 秒以上并持续出新帧；第 22 集真实播完后自动切到第 23 集并继续播放。
- **真实媒体**：同一批分集另做整集下载、按片源密钥解密、`ffprobe` 读取时长和整集静音解码，全部通过，解码时长与目录声明一致。
- **自动化**：`npm test` 主单元 778 项与平台检查 119 项全部通过（失败 0、跳过 0）；依赖审计已知漏洞 0 项。
- **安装与更新**：安装包版本信息为 `6.38.0`，安装配置检查通过，更新清单与安装包一一对应。本机未执行安装、重装、卸载和旧版应用内更新的实机验收，这些步骤需要在 Windows 上单独确认。

## ⚠️ 已知问题

- 本轮只逐集验证目标剧的 5 个分集，其他剧集仍按线路逐集判断，不由此推广。
- 官网公开可访问范围外或需要官方授权的内容可能无法播放，应使用官方支持的入口。
- DASH、官方 DRM/CDM 和所有 GPU/编码组合尚未通过验证；接口与媒体地址仍可能变化。
- 播放验收全程静音，未做声音输出质量验收。
