# 红果短剧 6.35 候选发行记录

记录日期：2026-11-25。版本 `6.35.0`，目标标签 `v6.35`，仅面向 Windows x64。该版本承接 `v6.34` 的播放稳定性改造，并修复 Windows 安装候选检查器在读取 ASAR 内路径时使用 POSIX 分隔符的发布阻塞问题。`v6.34` 冻结标签未移动、未发布。

## 本轮修复

- Windows 安装验收器按运行环境规范化 ASAR 内部路径，能够在 Windows 构建产物中核对 `src/native/app-entry.cjs`、`main.js` 和账号卸载模块。
- 保留 v6.34 的账号会话、播放调度、有限恢复、诊断脱敏、NAS 资料归属和卸载清理改造。
- 不宣称 App 播放接口 HTTP 200 空正文已恢复；官网公开线路仍只处理官方明确允许公开访问且通过完整性检查的分集。

## 下载与更新

正式发布后只上传以下两个资产：

| 文件名 | 平台 / 架构 | 说明 |
| --- | --- | --- |
| `hongguo-downloader-6.35-win-x64-setup.exe` | Windows x64 | 向导式安装版 |
| `latest.yml` | Windows x64 | 应用内更新清单 |

`latest.yml` 必须由最终安装 EXE 字节生成，保留该文件以兼容 v6.2–v6.6 旧客户端的更新提示和下载流程。v6.33 用户通过 GitHub 正式版本检查应能发现 `v6.35`；正式发布后必须运行独立的 `v6.33 → v6.35` Windows 更新验收。

## 验证门禁

- `npm test`、渲染构建、依赖审计和 CodeQL 必须针对同一 `v6.35` 提交通过。
- Windows x64 候选必须通过实际安装、同版本重装、账号资料保留、真正卸载清理和真实 `v1.80 → v6.35` 升级验收。
- 发布工作流只接受同一标签提交的成功 Test、Windows 候选及安装回执，并核对安装 EXE 与 `latest.yml` 的文件名、大小、SHA-256、SHA-512。
- 公开发布后运行 `.github/workflows/verify-live-update.yml`，输入 `from_tag=v6.33`、`to_tag=v6.35`，确认旧版提示、下载、校验、重启安装、自动启动、版本号和资料保留。

## 已知限制

- 仅支持 Windows x64，安装 EXE 未代码签名，首次运行可能出现 SmartScreen 提示。
- App 播放接口空响应、受限或付费分集授权、所有 GPU/HEVC 环境和安装中途自动回滚仍不作保证。
