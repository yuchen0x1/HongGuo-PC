## 6.25 · 2026-11-21

## 6.24 · 2026-11-21

- 修复部分剧集提示「App：播放接口空响应」无法在线播放的问题：空响应后按「当前 V5 请求 → 备用官方主机 → 签名 video_tab GET」阶梯恢复，已在多部真实剧集验证可重新取得完整分集。
- 明确拒绝与限流仍立即停止；整轮失败才换新匿名身份，总预算有界。
- 仅支持 Windows x64；不更改资料格式或安装升级方式。

## 6.23 · 2026-11-21

- 数据文件损坏后可恢复：每次成功保存把验证过的新文档镜像到 `data.json.bak`；读取失败且备份有效时，设置页提供「恢复数据备份」，恢复保留损坏原文件并要求重启。
- 保存不再覆盖历史遗留的 `data.json.tmp`，改为每次独占创建新暂存文件；Windows 瞬时占用导致改名失败时复用已写好的暂存内容重试。
- 损坏文档不会覆盖有效备份；恢复前核对原文件未变化，且必须明确确认。
- 仅支持 Windows x64；不更改资料格式或安装升级方式。红果完整分集播放尚未恢复。

## 6.22 · 2026-11-21

- 收紧开发渲染器信任边界：打包应用忽略继承的 `VITE_DEV_SERVER_URL`，开发模式只接受 HTTP loopback 地址。
- 远程主机、局域网地址、凭据、路径、查询参数、hash 和超长环境值均不会成为受信 renderer 来源；窗口加载、媒体访问与 IPC 使用同一过滤结果。
- 增加开发地址和 renderer 文件 URL 的正向/负向回归，并修复 VM 测试替身对新模块的依赖。
- 仅支持 Windows x64；不更改本地资料格式或安装升级方式。红果完整分集播放尚未恢复。

## 6.21 · 2026-11-21
