本次更新包含播放稳定性改造及 Windows 安装验收修复：保留原有扫码登录和播放器，统一会话检查、取源调度、媒体地址管理及故障恢复，并增加可脱敏导出的播放诊断。修复 Windows 安装包检查器无法按 Windows 路径读取 ASAR 内文件的问题。App 播放接口空响应仍存在，官网公开线路仅处理官方允许公开访问的完整分集。

## ✨ 新增功能

- **播放诊断**：设置新增独立区域，可查看账号会话、播放身份、请求配置、当前线路、最近错误、恢复次数、加载和解码状态，并支持检查账号、测试连接及导出脱敏报告。
- **统一播放调度**：红果取源通过同一管理器处理账号状态、并发请求、取消和总超时，区分账号身份、播放设备、请求与媒体会话。
- **官网公开播放线路**：在官方页面明确允许公开访问时，校验分集身份、访问范围、媒体有效期、无加密标记及完整时长后使用官方媒体，不将预览当作完整分集，不解锁付费内容。
- **播放中扫码登录**：符合条件的取源失败可自动显示现有扫码窗口，手机确认后重新尝试当前分集；窗口支持浅色、深色和窄屏，扫码状态不替代官方内容授权。

## 🔧 改进与优化

- **账号会话**：有效性检查、过期处理和并发刷新复用现有登录系统；临时网络失败保留加密凭据并显示真实状态，退出后阻止晚到请求恢复旧会话。
- **请求配置**：集中记录 App 接口、画像、版本、请求头、签名关联字段和超时；保留可测试的兼容配置及线路统计，不自动下载第三方签名或账号凭据。
- **有限恢复**：区分取源、媒体读取、解密与解码故障。按证据刷新到期地址、等待网络恢复或使用既有兼容解码，保留播放进度和暂停意图；恢复受最大次数、总预算及取消约束。
- **播放状态**：取到地址、媒体加载和首帧成功分别记录；切集、自动连播和手动重试沿用统一入口。

## 🐛 问题修复

- **取消后的后台收尾**：解密取消后继续登记实际资源清理，修复立即重试同集时继承旧取消结果及收尾脱离退出、安装保护的问题。
- **拖动与片尾恢复**：正常拖动取消旧媒体读取时不再误报连接中断；恢复进度接近片尾时仍可继续播放并触发真实自动连播。
- **候选与取消诊断**：可恢复的中间片源失败不再提前显示为整集故障；已取消操作不再更新当前播放诊断。
- **暂停与扫码提示**：正常播放后的长暂停不再耗尽初始恢复期限；离开播放器或关闭画中画会清理扫码提示，阻止晚到结果重新取源。
- **失效地址与拒绝响应**：不再无限复用过期地址，明确鉴权拒绝和限流停止自动重试；HLS 媒体拒绝不会被直接当成解码错误。
- **NAS 资料归属**：改用 XML 解析校验 NFO 身份，避免把注释、描述或畸形 XML 中的身份文字误认为本项目文件；保留用户现有文件和独占写入保护。

## 🔒 安全与兼容性

- **账号凭据**：继续使用 Electron `safeStorage` 的系统加密后端，不回退明文保存；按 Cookie 有效域、路径、安全属性及到期信息限制发送。登录网页有效不代表 App 播放鉴权有效。
- **隐私说明与清理**：扫码窗口明确说明账号资料和凭据仅在本机保存、经系统加密且仅用于红果官方服务；退出登录或真正卸载时清除对应账号数据，覆盖升级保留。清理失败会阻止卸载继续。
- **诊断脱敏**：报告只接受固定状态、数值及内置配置标识，不导出完整 Cookie、账号和设备标识、密钥、签名或完整媒体地址。
- **Windows 安装器**：仅发布 Windows x64；真正卸载时清理对应账号会话，覆盖升级保留账号资料。安装 EXE 仍未签名，首次安装可能出现 SmartScreen 提示。
