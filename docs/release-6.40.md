# 红果短剧 6.40 发行（修复安装包截断）

6.40（内部 `6.40.0`）取代已撤回的 6.39：修复安装包把主程序截断、安装后无法启动的问题。功能与 6.38 相同。

## 缺陷与根因

- 6.39 首发安装包安装后启动报"此应用无法在你的电脑上运行"。
- 证据：把该安装包装进独立临时目录，落地的 `红果短剧.exe` 为 103,537,547 字节，是构建产物（250,521,088 字节）的前半截；`app.asar`、FFmpeg、FFprobe 完整；安装器退出码 0、无报错。
- 对照：6.37、6.38 的安装包在同一台机器安装后主程序均完整。
- 原地重建的 6.39 也失败过一次：只释放卸载器、没有主程序。改用暂存副本打包后通过。
- 结论：缺陷在 NSIS 打包阶段读到了被文件同步/占用而截断的输入；项目位于云同步目录，具体触发者未取得直接证据，不作定论。
- 6.39 的标签被 GitHub 的发行不可变策略永久保留，无法按原版本号重发，故修复版为 6.40。

## 修复

- 打包流程改为：先把 `dist/win-unpacked` 复制到**不参与云同步的临时目录**，逐文件比对摘要；再用 `electron-builder --prepackaged` 从该副本生成安装包，产物先落在临时目录。
- 新增 `scripts/check-installer-payload.cjs`：把安装包装进独立临时目录，逐字节比对 `红果短剧.exe`、`resources/app.asar`、`resources/bin/ffmpeg.exe`、`resources/bin/ffprobe.exe` 与构建产物，并校验主程序为 x64 PE 镜像；不一致即失败；没有本地构建产物时跳过（CI 不构包）。
- 发布门禁：载荷校验通过，并用**安装出的程序**完成逐集播放实测后才发布。
- 开源状态：完整源码在公开仓库，`NOTICE` 与 `README` 恢复为"完整源码见本仓库"。
