## 本轮范围

- 保留现有扫码登录，补齐会话有效性、过期、重启恢复、并发刷新、Cookie 范围和退出清理；账号与播放设备只作本地关联，不伪造平台授权。
- 红果播放统一经过 `PlaybackManager`，集中请求配置、签名关联字段、线路与超时，并区分账号、设备、请求和媒体的生命周期。
- 增加官网公开完整分集线路；只有官方明确公开、分集身份与访问范围匹配、地址有效且无加密标记、完整时长一致时才返回媒体。不取用受保护播放器密钥或绕过付费权限。
- 区分 14 类故障，在次数与总预算内处理网络、媒体地址及兼容解码，传播取消并尽可能保留进度和暂停意图。
- 设置新增独立「播放诊断」与检查账号、测试连接、导出报告三个操作；固定字段脱敏，分开统计取源、媒体加载和首帧。
- 登录弹窗使用独立内存 Cookie 分区；退出、过期及启动迁移清理历史官方 Cookie。最小包入口与 NSIS 助手在真正卸载时清理账号，更新/覆盖安装跳过清理。
- 符合条件的取源失败自动显示现有扫码入口；确认后仅重试当前播放选择。窗口展示本机存储、系统加密、仅用于官方服务及退出/卸载清理的隐私说明，不将登录状态等同内容授权。
- 修复解密取消收尾、立即重试同集竞态、拖动进度误报媒体中断、中间候选失败提前上报、取消后更新诊断、片尾恢复被跳过、长暂停耗尽初始预算及离开播放后的扫码提示；NAS NFO 归属改为 XML 解析。保留搜索、下载、NAS、剧库、观看记录和更新原有入口，不作无证据的兼容承诺。

## 升级与限制

覆盖升级保留现有资料及加密账号，恢复后仍检查会话有效性；过期、无效或无法解密时需重新扫码。真正卸载会清除对应账号会话，请勿以先卸载作为常规升级步骤。清理失败不得假报成功，更新路径不触发账号卸载助手。

当前仍未恢复 App HTTP 200 空正文；网页 Cookie 没有证明具备 App 鉴权能力，官网公开线路也不覆盖需要登录、付费或受保护的所有分集。不通过反复换身份或凭据绕过拒绝，不依赖第三方提供账号或签名。

仅支持 Windows x64，安装包仍未代码签名，不能宣称解决 SmartScreen 或所有 GPU/编码兼容性。有限恢复、历史配置回退不保证官方接口永久兼容；安装中途故障自动回滚亦未完成真实验收。本轮最终更新日志及发行结论由冻结版本和实际验收补齐。
