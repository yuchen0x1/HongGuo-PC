# 红果短剧 6.5

状态：候选源码发行目标（内部版本 `6.5.0`，标签 `v6.5`）。发布日期：2026-11-08。Release：https://github.com/yuchen0x1/HongGuo-PC/releases/tag/v6.5。仅维护 Windows x64；Windows EXE 未配置代码签名。

## 主要变化

### 设置页导航与检索

- 设置页新增 11 个分类锚点：外观、快捷键、画中画、内置来源、自定义源、播放缓存、弹幕、下载、代理、追剧、配置位置。
- 分类导航支持平滑滚动与当前位置高亮；关键词搜索会筛选分类按钮，输入关键词后按 Enter 跳转到第一个结果。
- 搜索只调整导航，不卸载设置内容，避免丢失未保存输入。

### 窄窗口播放工具栏

- 播放页低频窗口与播放操作收进“更多”菜单：小窗模式、竖屏选集、隐藏/显示按钮、边框、置顶。
- 布局切换保持直接可见；菜单支持点击外部关闭、Escape 关闭和关闭后恢复焦点。
- 宽窗口仍以原有布局显示，窄窗口自动改为下拉菜单。

### 下载管理批量整理

- 新增选中任务工具栏，直接显示已选数量并支持批量停止、重试、删除和取消选择。
- 批量停止复用单任务停止接口，仅处理下载中、排队中和等待重试的任务；批量重试仅提交失败或已停止任务。
- 删除仍走已有确认流程，并继续区分是否删除本地文件。

### 观看记录批量整理

- 观看记录支持逐条选择、全选当前列表、跨筛选保留选择和批量移除。
- 批量移除前明确确认；界面说明“视频文件、下载任务和本地剧库不会受影响”。
- 主进程新增 `remove-watch-history-batch`，校验数组、去重并只删除播放记录键；不删除视频文件或注册剧集。
- 新增集成测试覆盖参数校验、去重、返回数量、剧库保留和更新事件。

### 安全与构建

- 本轮未新增运行时依赖；复核 Dependabot 告警为零。
- 保持 6.4 已完成的依赖安全升级和本地媒体协议防护；更新发布工作流的 6.5 版本、产物名称和校验清单。
