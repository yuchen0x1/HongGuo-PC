# 更新记录

## 6.9 · 2026-11-13

- 优化退出与更新安装：删除任务、清理缓存或导出文字资料时，等待处理完成再退出，减少文件与记录不同步。
- 修复分集列表缺失：来源临时只返回部分分集时，保留剧库中已知的分集。
- 修复 Ctrl+K 面板悬停选项后，回车打开错误页面的问题。
- 修复来源加载期间，全局搜索未自动执行的问题。

## 6.8 · 2026-11-12

- 恢复 Windows 安装版的应用内更新，支持下载进度展示和确认后重启安装。
- 优化更新安装时机，等待下载、合并、转码及资料保存完成，避免中断任务。
- 修复下载取消、重试和恢复时的重复任务，以及 NAS 任务状态不同步的问题。
- 修复切集黑屏、播放卡顿恢复和缓存误用的问题。
- 加强下载与删除时的文件保护，修复搜索排序、弹幕资料恢复和退出保存的问题。

## 6.7 · 2026-11-10

- 修复无关视频被误认成分集，参与合并或被自动删除的问题。
- 优化退出保存，等待设置保存及删除、清理操作完成，减少设置丢失和记录不同步。
- 优化播放卡顿提示，片源长时间无响应时可重试本集，避免画面一直停在上一集。
- 优化切集和自动连播，保留上一集画面至新片源显示，减少黑屏闪烁。
- 修复 Ctrl+K 搜索落在隐藏页签，以及浅色模式下拉框样式异常的问题。
- 调整本版更新方式：检测到新版后提醒，并打开下载页面手动安装。

## 6.6 · 2026-11-09

- 修复切换浅色模式后，外观和海报大小下拉框仍显示深色背景的问题。
- 修复浅色模式下搜索框、命令面板和选集控件残留深色样式的问题。

## 6.5 · 2026-11-08

- 新增设置分类导航与关键词搜索，输入关键词后可按回车跳转到对应设置。
- 优化窄窗口播放工具栏，将不常用的窗口操作收进“更多”菜单。
- 新增下载任务批量停止、重试、删除和取消选择操作，删除前保留确认提示。
- 新增观看记录多选、全选和批量移除，切换筛选时保留选择；移除记录不删除视频。

## 6.4 · 2026-11-06

- 新增双击画面切换全屏；空格短按播放或暂停，长按临时以 2 倍速播放，松开恢复。
- 新增临时倍速快捷键设置，记住音量、静音状态和常用倍速。
- 优化切集、自动连播和播放模式切换，减少黑屏与白屏闪烁。
- 新增使用系统默认播放器打开已完整下载分集的入口。
- 修复部分未加密片源无法播放的问题，对不支持的视频编码给出明确提示。
- 更新深色界面的玻璃质感、发光边框和进度动效，适配减少动态效果偏好。
- 更新安全组件，加强本地视频访问与外部链接保护。

## 6.3 · 2026-11-05

- 修复更新日志偶发无法加载的问题，减少重复联网请求。
- 新增更新日志本地缓存，网络异常时显示上次同步内容和时间，并支持重新同步。

## 6.2 · 2026-11-04

- 新增同系列跨季切换，可在发现页和“搜索与下载”选集区直接切换同来源的不同季。
- 优化季数识别，避免把同名或不同来源的剧集合并。
- 优化页面和播放器滚动样式，隐藏滚动条并保留滚轮、触摸与键盘滚动。
- 调整平台支持范围，自本版起仅发布和维护 Windows x64 版本。

## 6.1 · 2026-11-04

- 调整更新日志页面，将检测更新移至顶部，下方按版本展示更新内容。
- 移除启动公告横幅和公告设置，简化界面。
- 修复更新来源不一致的问题，统一从当前项目获取新版和下载。

## 6.0 · 2026-11-04

- 新增 Windows 自定义标题栏，支持拖动、双击最大化和窗口控制。
- 更新应用图标，统一标题栏、侧栏、任务栏和安装包图标。
- 新增搜索结果跨来源合并，同一部短剧集中展示多个可选来源。
- 内置六个短剧来源，可在设置中开关，并支持采集源在线播放。
- 新增侧栏“更新日志”页面，集中查看公告和检测更新。
- 将应用内更新切换到当前项目的发行版本。
